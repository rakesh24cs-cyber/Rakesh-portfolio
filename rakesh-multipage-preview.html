About me

I’m a computer science student who likes seeing a feature through from start to finish: a sketch on paper, a form on screen, a query in the database.

Food ordering and attendance tracking are everyday problems, so I picked them to practise building software people could actually use.

Education
B.Tech / B.E., Computer Science
Focus
Web apps with Java and MySQL
Career goal
Grow into a full-stack developer on a product team

How I build

  1. 1

    Understand

    Write down who uses it and what they need to finish.

  2. 2

    Model the data

    Sketch the MySQL tables before any screen exists.

  3. 3

    Build

    Connect the interface to the Java logic one feature at a time.

  4. 4

    Test and ship

    Try it on a phone, fix what breaks, then push to GitHub.
